# Teknologappen public website

Static, bilingual information site for `teknologappen.se`. It links to the student app and the
administrator frontend and contains the legal and merchant information shown to ticket buyers.

## Development

```sh
pnpm install
pnpm dev
```

The development server runs on <http://localhost:5176>. Build the static site with `pnpm build`; the
result is written to `build/`.
